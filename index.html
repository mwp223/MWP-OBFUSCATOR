⚙️
Opcode randomization
All 38 Lua 5.1 opcodes are remapped to a random bijection each build. Static disassemblers produce complete garbage — MOVE might be opcode 23 this build, 7 next build.
38 opcodesper-build unique
🔐
Triple-pass XOR encryption
Every instruction array is encrypted three times: forward with the low byte of an LCG stream, backward with the mid byte, forward again with the high byte. Different key per proto per build.
LCG keystream3 passesper-closure keys
🔒
String encryption
Each string constant gets its own independent random key. Strings are encrypted individually — compromising one key leaks nothing about any other string in the script.
per-string keysLCG-XOR
🛡️
CRC32 integrity check
A standard CRC32 is computed over the encrypted instruction array at obfuscation time and verified at runtime before decryption. Any modification to the bytecode crashes the script instantly.
runtime verificationtamper detection

Anti-tamper probes
The VM probes for hooked globals and debug hook injection at startup. Any modification to the Lua environment triggers a silent crash before execution begins.

How it works

Two steps, no server

bash · step 1: compile
# Install Lua 5.1 compiler
# Windows: choco install lua
# Linux: apt install lua5.1
# Mac: brew install lua@5.1

# Compile your script to bytecode
luac5.1 -o myscript.luac myscript.lua

# On Windows (just "luac")
luac -o myscript.luac myscript.lua
bash · python CLI (alternative)
# Direct CLI — requires luac in PATH
python obf.py script.lua

# Deterministic build
python obf.py script.lua --seed 1337

# Double VM (nested layers)
python obf.py script.lua --double

The web tool runs the full obfuscator engine in your browser — no uploads, no server, no Python required. Just compile your script to .luac with the standard Lua 5.1 compiler and drop it in.

The obfuscated output uses only bit32, string.unpack, and table.pack — all available natively in Roblox Luau. Copy and paste directly into any executor or place file.
